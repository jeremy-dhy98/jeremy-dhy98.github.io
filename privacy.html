Privacy Policy

Effective Date: August 4, 2026

Coding For Freedom ("we," "our," or "us") operates the website and the APOND application integration. This Privacy Policy explains how we collect, use, and protect information when you interact with our platform or services.

1. Information We Collect

APOND is an internal automated content dispatch tool. We only collect minimal information necessary to publish educational media via official APIs (such as TikTok API). This includes:

  • API authorization tokens provided voluntarily via standard OAuth flows.
  • Basic engagement analytics for internal logging and system optimization.

2. Use of TikTok API Data

Our application uses TikTok API services solely to upload, publish, and manage educational and informational videos directly to authorized accounts. We do not sell, rent, or transfer any user data obtained via TikTok API to third-party ad networks or data brokers.

3. Data Protection & Security

We enforce strict security protocols, including encryption and secure credential storage, to prevent unauthorized access, disclosure, or misuse of API authorization keys.

4. Data Retention and Deletion

Tokens and operational logs are stored securely and purged when no longer required for content distribution workflows. Users can revoke API permissions at any time via their TikTok account settings.
